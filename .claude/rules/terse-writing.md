# 写作纪律：注释与文档只写当下

本规则自动加载，适用于所有注释、文档、提交信息、回复文字。

## 两条硬规矩

1. **不引用。** 不写「见 xxx.md §7」「按 AGENTS §5」「遵循某某约定」这类出处。文档会更新、问题会修复，引用会腐烂；读者为一句过期引用要同步一堆无关文字。要表达什么就直接写出内容本身。

2. **不追述。** 不讲历史、背景、原由、「当初为什么这样」「踩过什么坑」「实测发现」。只有一种例外：不写就无法理解当前代码的一段背景，且必须压到一两句。多数时候删掉不影响任何人。

## 注释只写三件事

做什么、怎么做、必要的简单原因。一两行为主。

- 名字已经说清的，不写注释。
- 注释里不用反引号、粗体、列表符号等 Markdown 修饰，用普通句子。
- 整段说明放进专门文档，不放进代码。

## 自查

写完问一句：相关的 md 下次改版，这段文字会不会变成错的或无关的？会，就删。
