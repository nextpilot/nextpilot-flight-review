# PlotScope 用户手册

本目录只写“装好之后怎么用”。编译、架构和扩展开发见 [`../develop/`](../develop/README.md)。

| 文档 | 内容 |
|---|---|
| [快速开始](getting-started.md) | 启动、打开日志、选通道、保存工作区、主界面说明 |

## 建议阅读顺序

1. 第一次使用：快速开始。
2. 不确定文件能不能打开：支持的数据格式。
3. 要搭对比工作区：绘图与交互。
4. 要做派生计算或保存习惯：变换、脚本与设置。
