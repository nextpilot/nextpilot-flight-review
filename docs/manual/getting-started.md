# 快速开始

## 启动

发布包运行 `plotscope-gui`（命令行工具为 `plotscope`）。源码编译见 [`../develop/building.md`](../develop/building.md)。

启动后默认深色界面：左侧数据源，中间绘图区，右侧属性与对象树，底部日志面板。顶部 Ribbon 按「开始 / 文件 / 数据 / 绘图 / 脚本 / 协议 / 分析 / 视图」分八页。

## 打开第一份日志

- `文件 → 打开文件`，或按 `Ctrl+O`；也可以把日志文件直接拖进左侧数据源面板。
- 支持一次选多个文件，每个文件成为一个独立数据源。

加载完成后，数据源树按「源 → 通道 / 参数 / 消息」展开。源行右侧常驻 `N 通道 · 采样点 · 时长 · 采样率` 摘要。双击通道，或把通道拖进画布，即可绘图；已绘制的通道名跟随曲线配色，未绘制的保持弱化灰。

## 主界面

| 区域 | 用途 |
|---|---|
| 顶部 Ribbon | 八页命令入口，按功能分组 |
| 左侧数据源 | 打开/关闭源，查看通道、消息、参数；源可重命名 |
| 中间绘图区 | 多页签；单页可横向/纵向拆分，也可按 `m × n` 铺网格 |
| 右侧属性 | 当前对象的参数，可直接编辑（见[绘图与交互](plotting.md)） |
| 右侧对象树 | 当前页的画布与曲线层级 |
| 底部日志 | 加载、错误、扩展与运行日志 |

面板可拖动停靠、浮动或自动隐藏；`视图` 页切换面板显隐。

## 多源对比

1. 打开两份以上日志。
2. 在数据源上右键重命名，图例显示为 `源别名 · 通道名`。
3. 选中两个源里的同名通道，用「对比同名通道」叠到当前画布。
4. 用源右键菜单或时间对齐命令选择起点/中心/终点对齐，也可手动设时间偏移。

时间偏移、源别名和画布内容随 `.psl` 保存。

## 保存和恢复工作区

- `Ctrl+S` 保存工作区（`.psl`），`Ctrl+Shift+S` 另存。
- 设置里可勾选「启动时恢复上次布局」。

`.psl` 保存数据源路径、别名、时间偏移、画布布局、图型、轴设置和变换配方。数据文件本身不打包进 `.psl`，换机器时要保证原文件路径仍可访问。

## 命令行

`plotscope` 是无界面的 CLI / headless 入口，适合脚本化与自动化：

```bash
plotscope --list-parser       # 查看支持的格式
plotscope --info demo.csv      # 查看文件解析摘要
plotscope --script x.lua       # headless 跑脚本
plotscope --batch <dir> x.lua  # 批量处理目录
plotscope --mcp-bridge         # 启动 MCP server（stdio JSON-RPC）
```

完整参数见 `plotscope`（无参数运行打印用法）。

## 常见问题

**打开后没有曲线？** 检查数据源树里是否勾选了通道；双击通道或拖进画布。

**图例名字太长？** 给数据源改一个短别名，图例变成 `别名 · 通道`。

**时间轴对不齐？** 先确认各源的时间列识别正确（见[支持的数据格式](formats.md)），再用对齐命令或手动偏移。

**重启后布局没恢复？** 确认设置里「启动时恢复上次布局」已勾选，并且上次退出前保存过 `.psl`。
