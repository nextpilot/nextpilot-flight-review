# 快速开始

## 启动

发布包直接运行 `plotscope_app`。源码运行的编译步骤见 [`../develop/building.md`](../develop/building.md)。

启动后默认是深色界面，左侧数据源，中间绘图页，右侧属性/对象树，底部日志。

## 打开第一份日志

- `文件 → 打开文件`，或按 `Ctrl+O`。
- 也可以把日志文件拖进左侧数据源面板。
- 支持一次选多个文件；每个文件成为一个独立数据源。

加载完成后，数据源树按“源 → 通道/参数/消息”展开。双击通道，或把通道拖进画布，即可绘图。

## 主界面

| 区域 | 用途 |
|---|---|
| 顶部 Ribbon | 文件、数据、绘图、脚本、协议、视图等命令入口 |
| 左侧数据源 | 打开/关闭源、查看通道、消息、参数；源可重命名 |
| 中间绘图区 | 多页签；单页可继续横向/纵向拆分，也可按 `m × n` 铺画布 |
| 右侧属性 | 当前对象、曲线、轴、图型参数 |
| 右侧对象树 | 当前页的画布与曲线层级 |
| 右侧脚本 | Lua 5.4 脚本编辑、绑定输入、预览/应用 |
| 底部日志 | 加载、错误、扩展和运行日志 |

面板可以拖动停靠、浮动或自动隐藏；`视图` 页可以切换面板显示。

## 多源对比

1. 打开两份以上日志。
2. 在数据源上右键重命名，图例会显示为 `源别名 · 通道名`。
3. 选中两个源里的同名通道，用“对比同名通道”叠到当前画布。
4. 用源右键菜单或时间对齐命令，选择起点/中心/终点对齐；也可以手动设时间偏移。

时间偏移、源别名和画布内容会随 `.psl` 保存。

## 保存和恢复工作区

- `Ctrl+S` 保存布局；`Ctrl+Shift+S` 另存布局。
- `Ctrl+Shift+O` 打开 `.psl` 布局。
- 设置里可勾选“启动时恢复上次布局”。

`.psl` 保存数据源路径、别名、时间偏移、画布布局、图型、轴设置和变换配方。数据文件本身不打包进 `.psl`，换机器时要保证原文件路径仍可访问。

## 常见问题

**打开后没有曲线？**
检查数据源树里是否勾选了通道；双击通道或拖进画布。

**图例名字太长？**
给数据源改一个短别名，图例会变成 `别名 · 通道`。

**时间轴对不齐？**
先确认各源的时间列识别正确，再用对齐命令或手动偏移。

**重启后布局没恢复？**
确认设置里的“启动时恢复上次布局”已勾选，并且上次退出前保存过 `.psl`。
