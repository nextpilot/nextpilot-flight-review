# 绘图与交互

## 新建图页

Ribbon `绘图` 页提供图表画廊。新建图页会沿用当前画布的可见通道；也可以先不选通道，建空画布再拖曲线。

当前图型：

| 图型 | 用途 |
|---|---|
| 时间序列 | 时间轴曲线，最常用 |
| XY 曲线 | 两个通道做 X-Y |
| 散点图 | 二维散点 |
| 柱状图 | 离散量柱状对比 |
| 直方图 | 样本分布 |
| 频谱 FFT | 幅值频谱 |
| 3D 轨迹 | 三维空间轨迹（轻量正交投影） |
| 地平仪 / 罗盘 / 表盘 | 姿态、航向、单值仪表 |

3D 曲面和 GPS 地图在画廊里有入口，但当前版本未完成，按“当前边界”处理。

## 画布布局

- 一个绘图页里可以横向、纵向拆分画布。
- 也可以用 `m × n` 布局选择器一次性铺网格，再继续拆。
- `视图` 页可以切换数据源、属性、脚本、日志面板。
- 页签可新建、关闭、切换；布局随 `.psl` 保存。

## 缩放和平移

- 滚轮：缩放时间轴。
- `Ctrl + 滚轮`：缩放 Y 轴。
- 左键拖动：平移。
- 框选：拉出矩形放大到该区域。
- 双击：复位到自动范围。
- 工具条提供放大、缩小、自适应和复位。

滚轮缩放的锚点在鼠标指针处，避免缩放后目标曲线跑出视野。

## 游标

- 十字游标：显示当前时间与各曲线在该时刻的值。
- A/B 游标：分别放置 A、B，显示 `Δt`、逐曲线 `Δy` 与斜率。
- 游标线、标记点和读数都在画布内绘制；导出 PNG 时会一并带上。

## 曲线与属性

在画布上右键可以：

- 添加/删除曲线。
- 打开曲线属性，改颜色、线宽、图例名、轴归属。
- 切换图型、导出 PNG、导出当前时间窗 CSV。
- 调整网格、边框、图例显示。

右侧属性面板和对象树与画布双向同步：选中对象树里的画布或曲线，属性面板显示对应参数。

## 导出

| 导出 | 入口 | 内容 |
|---|---|---|
| PNG | 画布右键 / 文件页截图 | 当前画布或当前页，含曲线、游标、图例 |
| CSV 长表 | 画布右键 | 当前可见时间窗，按曲线展开 |
| `.psl` | `Ctrl+S` / `Ctrl+Shift+S` | 工作区布局与数据源引用 |

导出 CSV 只包含当前可见时间窗，不导出全量数据；需要全量时先缩放到目标范围。
