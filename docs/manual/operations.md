# 变换、脚本与设置

## 数据变换

在曲线或数据源通道上打开“变换”，`Ctrl+T` 也可打开当前通道的变换面板。变换前可以预览 before/after；应用后生成派生通道，并继承来源曲线颜色。

当前变换：

- 绝对值、比例、偏移、时间平移。
- 微分、梯形积分。
- 滑动平均、滑动 RMS、滑动方差、滑动标准差。
- 尖峰剔除、阈值二值化、样本计数、相邻样本 `Δt`。
- 四元数 `w/x/y/z` → `roll/pitch/yaw` 三条派生通道。

变换配方随 `.psl` 保存；删除派生通道不会删除原始源数据。

## Lua 脚本

右侧脚本面板使用 Lua 5.4。脚本可以绑定 1–4 个输入通道，预览后应用到当前画布。

可用 API：

| API | 用途 |
|---|---|
| `ps.ch` | 当前绑定输入通道 |
| `ps.time` | 时间轴 |
| `ps.plot(name, data)` | 输出一条曲线 |
| `ps.movingAvg(data, n)` | 滑动平均 |
| `ps.derivative(data)` | 微分 |
| `ps.integral(data)` | 积分 |
| `ps.scale(data, k, b)` | 线性缩放 |

示例：

```lua
local rate = ps.derivative(ps.ch(1))
local smooth = ps.movingAvg(rate, 5)
ps.plot("roll_rate", smooth)
```

脚本在受限沙箱中运行：不提供 `os`、`io`、`package`、`debug`，有指令预算和内存上限。脚本输出直接追加到当前工作区画布，不写回 `.psl`，重启后不会恢复。

## 设置

`文件 → 设置`，或 `Ctrl+,`。

设置对话框左侧是分类，右侧是当前分类的页面。通用页包含启动恢复、主题等 shell 级设置；数据源、绘图等模块可以往对话框里追加自己的页面。

当前可设置：

- 启动时恢复上次布局。
- 绘图相关默认项（网格、线宽、颜色等，按绘图模块提供的页面为准）。
- 扩展启停（在“关于 → 扩展”里）。

设置写入 `NextPilot/PlotScope` 配置。`文件 → 导出设置` 可以导出 JSON 或 YAML；JSON 适合脚本处理，YAML 适合人读和评审。

浅色主题尚未完成，当前只提供深色界面；计划见 [`../roadmap/theme.md`](../roadmap/theme.md)。

## 扩展启停

`帮助 → 关于 → 扩展` 里是扩展列表，勾选表示启用。

- 启停状态写入配置，启动时按配置跳过被禁用扩展。
- 改完勾选后可以点“重启应用”，让启停立即生效，不需要手动关开。
- 动态扩展的扫描目录、ABI 和 manifest 规则见开发文档。

## 日志与排错

底部日志 Dock 显示加载、解析、扩展和运行信息。日志同时写入配置目录下的日志文件，具体路径可在“关于”里打开日志目录。

常见错误：

- **格式不支持**：确认扩展已启用，文件后缀与实际内容一致。
- **通道为空**：文件可能只含参数/消息而没有对应 topic；看日志里的解析结果。
- **时间不对**：CSV 手动指定时间列；其他格式检查时间单位。
- **扩展没生效**：在扩展页确认勾选，点“重启应用”。
