# 变换、脚本与设置

## 数据变换

在曲线或数据源通道上打开「变换」，`Ctrl+T` 打开当前通道的变换面板。变换前可预览 before/after；应用后生成派生通道，并继承来源曲线颜色。

当前变换：

- 绝对值、比例、偏移、时间平移。
- 微分、梯形积分。
- 滑动平均、滑动 RMS、滑动方差、滑动标准差。
- 尖峰剔除、阈值二值化、样本计数、相邻样本 `Δt`。
- 四元数 `w/x/y/z` → `roll/pitch/yaw` 三条派生通道。

变换配方随 `.psl` 保存；删除派生通道不会删除原始源数据。

## Lua 脚本工作台

Ribbon `脚本` 页打开脚本工作台，由四个可停靠面板组成：

| 面板 | 位置 | 用途 |
|---|---|---|
| 脚本库 | 左侧 | 脚本文件浏览、新建、删除 |
| 编辑器 | 右侧 | 多标签代码编辑，语法高亮、断点、错误行标记 |
| 调试 | 右侧 | 调用栈、变量查看、API 速查 |
| 控制台 | 底部 | REPL，持久 VM，可直接试表达式 |

编辑器里设置断点后运行，命中即暂停，可在调试面板查看调用栈与变量、单步执行。脚本可在受限沙箱中访问当前数据集做派生计算与批量分析。

headless 场景用 `plotscope --script <file.lua>` 跑脚本、`plotscope --batch <dir> <script.lua>` 批量处理目录；外部代理可通过 `plotscope --mcp-bridge`（stdio JSON-RPC）驱动应用。

脚本在沙箱中运行：不提供 `os`、`io`、`package`、`debug`，有指令预算和内存上限。

## 设置

`文件 → 设置`，或 `Ctrl+,`。

设置对话框左侧是分类，右侧是当前分类的页面。通用页包含启动恢复、主题等 shell 级设置；数据源、绘图等模块可往对话框追加自己的页面。

- 启动时恢复上次布局。
- 绘图默认项（网格、线宽、颜色等）。
- 扩展启停（`帮助 → 关于 → 扩展`，勾选启用；改完点「重启应用」生效）。

设置在运行期间保存在内存（`文件 → 导出设置` 可导出为 JSON 存档，供备份或迁移）。`文件 → 导出设置` 导出 `plotscope-settings.json`，适合脚本处理与跨机迁移。

浅色主题尚未完成，当前只提供深色界面。

## 日志与排错

底部日志面板显示加载、解析、扩展和运行信息。日志同时写入配置目录下的日志文件，路径可在「关于」里打开。

常见错误：

- **格式不支持**：确认文件后缀与实际内容一致；`plotscope --list-parser` 核对支持列表。
- **通道为空**：文件可能只含参数/消息而没有对应 topic；看日志里的解析结果。
- **时间不对**：CSV 手动指定时间列；其他格式检查时间单位。
- **扩展没生效**：在扩展页确认勾选，点「重启应用」。

## 工作区与恢复

**保存工作区**：文件页「保存工作区」，输入一个名字，把当前的源清单与画布布局存成 `.psw`。同一个名字再存会整份覆盖。

**打开工作区**：文件页「打开工作区」，从列表里选一个，源条目与画布一起重建。预设文件在 `<AppData>/workspaces/` 下，拷走整个目录再拷回来即可换机器使用——前提是数据文件也在能访问到的路径上；路径变了可以把数据文件和 `.psw` 放同一目录下再打开。

**分享给没装解析器的机器**：保存时选 generic 方式（脚本调用 `workspace.preset.save` 带 `"generic": true`）。这种预设只记"数据在哪、画哪些通道"，不记解析参数；打开后源条目在，曲线按通道名匹配现载数据集。

**启动恢复档位**：设置（Ctrl+,）→ 数据页「启动恢复」。

- 仅布局（默认）：还原源条目与画布，不读数据。启动快；手动加载数据后曲线自动重绑。
- 完整：连数据一起加载。大文件启动会明显变慢。
- 关闭：不恢复上次会话。

**流式源不会自动连接**。无论哪个档位，上次开着的 UDP/串口源恢复后只是一个待连接条目，需要手动点连接——自动重连会卡住启动，而上次开着不代表这次同意连。
