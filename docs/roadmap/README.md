## 当前优先级

1. 浅色主题 token 化：把画布、数据源 Dock、属性/日志面板的硬编码颜色收进主题 token。
2. 脚本自动化 P1：对象句柄与绘图控制，仍走命令总线。
3. 格式补齐：Parquet、MAVLink tlog 原生解析、更多 MCAP 索引能力。

新的方案先在 `roadmap/` 写清目标、边界、验收和风险，确认后再进 `develop/` 或代码。
