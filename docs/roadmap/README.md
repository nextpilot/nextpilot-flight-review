# PlotScope 路线图

本文件是**长期规划与思路**：写方向、写取舍、写里程碑概览。不承担具体任务跟踪——任务一律走 gitee issue（里程碑挂同名 Milestone），完成后关闭 issue，不再往仓库写 plan 文件。

## 产品定位

轻量级绘图分析工具，对标 Origin 的思路：通用绘图分析底座 + 领域增值。面向无人机、嵌入式与车辆研发的离线日志分析为主，逐步补齐实时与协作能力。

## 路线分段

1. **通用绘图分析 + 脚本自动化**——多源数据、多画布、变换、脚本（已完成大半，见下表 M2 系列）。
2. **特色底座**——脚本工作台、数据编辑、自定义协议、工具箱生态。底座能力不与具体领域绑定。
3. **工具箱业务增值**——按领域（飞控/汽车/机器人/卫导）做内容包与领域面板，经统一机制分发，宿主不侵入领域知识。
