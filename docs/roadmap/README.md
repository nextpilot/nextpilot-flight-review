# PlotScope 路线图（Roadmap）

> 产品定位：轻量级绘图分析工具（靠拢 Origin）。三段路线：
> ① 通用绘图分析 + 脚本自动化 → ② 特色底座（脚本/数据编辑/代码编辑/自定义协议）→ ③ 工具箱业务增值。
>
> 完整方案与竞品分析见 `/PlotScope-产品定位与路线方案.md`（工作区根目录）。

## 排序依据（为什么是 M2.3 → M2.4 → M2.5）

1. **报告尽早落地**：PlotJuggler 若追加报告/分析能力会收窄差异化窗口（风险表第 1 条）；
2. 批量处理是脚本工作台的自然延伸（地基已热，成本低）；
3. 数据编辑器是大件（版本化/undo/派生联动），**必须先过 2.5.0 评审**才允许写代码；
4. Python 引擎前置条件（M2.1 脚本工作台）已满足，可按用户需求随时插队。
