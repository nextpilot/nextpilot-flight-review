## 技术要点（实现口径）

- **子进程隔离**：QProcess + 事件循环分片同步等待（与调试器暂停期同模式）；
  协议行必须 JSON（Python 警告污染 stdout 时按行丢弃兜底）。
- **大数组 shm**：C++ `QFile::write(QVector<double>)` → 元数据握手 →
  `np.memmap(path, '<f8')` 惰性映射；写回反向 `np.ascontiguousarray(...).tofile()`。
- **解释器发现**：`PLOTSCOPE_PYTHON` 环境变量 > PATH 上的 `python3`；
  `script.py.status` 报 available/interpreter/error_tail，找不到解释器优雅降级
  （每条意图明确报错，不弹窗轰炸）。
- **v1 已知边界**：`script.py.exec` 只注入**首表**数值列（ULog 单表场景够用，
  多表按需求再开）；`.py` 文档不入脚本库（草稿语义，保存能力随脚本库多语言扩展）；
  写回列的画布自动叠加（`derivedSeriesReady` 消费者）留待后续批次。
- **调试（远期）**：debugpy 协议接入是现成方案，一期不做。
