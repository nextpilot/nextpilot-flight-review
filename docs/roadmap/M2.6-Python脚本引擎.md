## 技术要点

- **子进程隔离**：Python 环境（版本/包/venv）千奇百怪，子进程 + JSON-line 协议
  保证崩溃隔离与超时杀进程；主进程零 Python 依赖（不链 libpython）。
- **大数组走共享内存**：100 万行 ×8B=8MB，JSON 序列化是灾难；shm 旁路 +
  元数据握手，双向 <200ms。
- **解释器发现**：设置页可指定 python 路径/venv；找不到时功能降级隐藏（不报错弹窗轰炸）。
- **调试（远期）**：debugpy 协议接入是现成方案，一期先不做。
