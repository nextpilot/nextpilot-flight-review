## 评审要回答的核心问题（2.5.0）

1. **版本粒度**：每次编辑一个 vN？编辑会话合并？（Rust kernel 列存不可变块是天然底座，
   COW 换页成本低，但版本爆炸要有 merge/回收策略）
2. **派生联动**：派生表达式引用的源列被编辑 → 重算时机（立即/失活标记/事务提交时）
   与重算范围（仅受影响派生）。
3. **undo 边界**：undo 栈随数据集生命周期还是随面板？跨数据集操作的入栈语义。
4. **与 LOD/live 的交互**：live 源数据允许编辑吗（一期倾向：只读源可编辑，live 源禁止）。
5. **内存红线**：100 万行 × 编辑副本的峰值内存预算与验收线。
