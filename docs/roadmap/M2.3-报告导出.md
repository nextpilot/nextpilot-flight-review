## 技术要点（实施前确认）

- **矢量导出**：画布底层是 QPainter/QCustomPlot 系，`QPdfWriter` 可直接产矢量 PDF——
  验收"不糊"基本免费；截图位图方案仅作降级兜底。
- **中文字体**：QPdfWriter 走 Qt 字体子系统，嵌 TrueType 子集即可，无需 fpdf2 类手工嵌入；
  实施时先写字体冒烟测试（中文标题/图例/表头三处）。
- **模板贡献**：一期模板只定义"节结构"（封面/画布/文本/元数据表），不做样式 DSL；
  扩展包 mount/unmount 语义与现有 DocEntry 对齐。
- **同路径原则**：`report.export` 是意图族，GUI Ribbon 按钮与脚本 `app.call` 走同一入口，
  headless CLI 也能导出（无人值守批量报告的地基，M2.4 复用）。

## 杀手场景（验收演示）

打开 2-3 个画布 → Ribbon「报告」→ 导出 PDF → 用系统阅读器打开：
封面有标题/时间/参数，正文每画布一节（矢量图 + 图注），结论页可编辑文本。
