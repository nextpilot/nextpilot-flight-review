# 画布交互重构：书签、A/B 与轴区手势

- 状态：已实施（2026-11-16）
- 相关代码：`src/application/modules/plotting/canvas/PlottingCanvas.*`、`PlottingTabs.*`、`PlottingSession.*`、`src/application/modules/datasource/manager/DataSourceSession.*`、`src/application/modules/runtime/include/ModuleBridge.h`
- 目标：左键保留选择/书签/测量；中键平移；右键单击菜单、右键拖动框选；支持单 X/单 Y 轴缩放与平移。

## 输入映射

| 输入 | 作用对象 | 行为 | 备注 |
|---|---|---|---|
| 左键单击 | 曲线/图例 | 选择曲线 | 空白清空选择 |
| 左键单击 | 时间书签 | 选中并跳转到该时间点 | 拖动时改为移动书签 |
| 左键拖动 | 时间书签 | 移动书签 | 超过 10 px 才算拖动，释放提交 |
| 左键拖动 | 空白 | 不导航 | 防止误触 |
| 左键双击 | 空白 | 重置视图 | 保留现有行为 |
| `Shift+左键` | 绘图区 | 添加时间书签 | 同时间已有书签则选中 |
| `Ctrl+左键` | 绘图区 | 直接生成一组 A/B | 以点击点为中心，默认间距约绘图区宽 10% |
| 左键拖动 | A/B 线 | 调整 A 或 B | 生成后直接可拖，无需再按 Ctrl |
| 中键拖动 | 绘图区 | 同时平移 X/Y | 不受工具按钮影响 |
| 中键拖动 | X 轴区 | 只平移 X | Y 不变 |
| 中键拖动 | Y 轴区 | 只平移 Y | X 不变 |
| 滚轮 | 绘图区 | 缩放 X 轴 | 以鼠标位置为中心 |
| `Ctrl+滚轮` | 绘图区 | 缩放 Y 轴 | 保留现有行为 |
| 滚轮 | X 轴区 | 只缩放 X 轴 | Y 不变 |
| 滚轮 | Y 轴区 | 只缩放 Y 轴 | X 不变 |
| 右键拖动 | 绘图区 | 双轴框选缩放 | 左上→右下放大，反向缩小；反向框 >70% 重置/自适应 |
| 右键拖动 | X 轴区 | 只框选 X 范围 | Y 不变 |
| 右键拖动 | Y 轴区 | 只框选 Y 范围 | X 不变 |
| 右键单击 | 绘图区/曲线/书签/图例/轴区 | 弹出对应菜单 | 只有未拖动时弹 |
| `空格+左键拖动` | 绘图区 | 双轴平移 | 无中键设备的备用方案 |
| `空格+左键拖动` | 轴区 | 单轴平移 | 另一轴不变 |
| `Esc` | 全局 | 按层级取消/清除 | 拖动 > 菜单 > 工具 > 测量 > 书签选中 |
| `Delete` | 时间书签 | 删除当前选中的书签 | 不删测量 |

## 右键状态机

- 右键按下：记录起点、命中对象；不弹菜单。
- 右键移动：超过 `QApplication::startDragDistance()` 后进入框选，画框。
- 右键释放：
  - 有效框宽高 > 6 px：执行框选缩放；
  - 否则：按按下时命中对象弹菜单。
- 命中优先级：时间书签标签框 > A/B 线 > 曲线 > 图例 > 空白。
- 图例在绘图区外，右键只弹菜单，不作为框选起点。
- 右键从曲线或书签开始拖动也允许转框选。
- X/Y 轴区在按下时锁定轴类型；后续只改锁定轴。

## 时间书签

- UI 统一叫“时间书签”，不再叫“时间标签”。
- 支持多个，属于数据源/会话，同页画布共享。
- `Shift+左键` 或右键菜单添加；同时间点不重复创建。
- 左键单击选中并跳转；拖动移动；`Delete` 删除选中；右键菜单也可删除。
- 当前存储仍按时间值索引；后续增加稳定 id，避免拖动后时间碰撞。

## A/B 测量

- 只保留一组 A/B。
- `Ctrl+左键` 直接生成 A/B，不再分两次点击：
  - 以点击点为中心，A 左 B 右；
  - 默认间距约绘图区宽度 10%，边界内整体平移。
- 生成后进入可编辑状态，A/B 线直接拖动，无需再按 Ctrl。
- 左键命中 A/B 线 ±10 px 进入拖动；允许 A 拖到 B 右侧，`Δt` 显示负值，不交换身份。
- 再次 `Ctrl+左键` 覆盖旧组；`Esc` 或右键“清除 A/B 测量”删除。
- `Delete` 不删测量，只删选中的时间书签。

## 轴区定义

- X 轴区：`plotRect().bottom()` 到画布底部，包含刻度文字区域。
- 左侧 Y 轴区：画布左边缘到 `plotRect().left()`。
- 右侧 Y 轴区：`plotRect().right()` 到画布右边缘，仅右轴存在时启用。
- 轴区悬停光标：X 轴 `SizeHorCursor`，Y 轴 `SizeVerCursor`。
- 双 Y 轴时 Y 轴缩放先同步左右轴，保持同一屏幕映射。

## 键盘

- `空格+左键`：临时平移；在轴区为单轴平移。
- 方向键：小步平移视图。
- `Ctrl+0`：重置视图。
- `Ctrl+加/减`：缩放 X 轴。
- `[` / `]`：上一个/下一个时间书签。
- `Esc`：按层级取消/清除。
- `Delete`：删除选中的时间书签。

## 实施顺序

1. 右键状态机与框选缩放，菜单移到 release。
2. 时间书签选中、拖动、删除，UI 文案改为“时间书签”。
3. A/B 直接生成、可编辑、`Esc`/右键清除。
4. 轴区命中、单轴滚轮缩放、中键单轴平移、轴区框选。
5. 空格平移、键盘导航、`Esc` 层级退出。
6. 构建、`ctest`、离屏启动验证，提交推送。

## 边界

- 左键不做框选缩放，避免和选择、书签拖动、测量冲突。
- 时间书签稳定 id 与重命名不在本轮强制范围；先保证拖动/删除行为。
- 同页光标联动、读值固定、A/B 吸附等建议项暂不进入本轮。
