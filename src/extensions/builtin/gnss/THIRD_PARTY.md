# Third-party data

`oem7_database.json` is copied from the NovAtel EDIE project:

- Source: https://github.com/novatel/novatel_edie (`database/database.json`)
- Copyright (c) 2023 NovAtel Inc.
- License: MIT

It is used as a data-driven OEM7 protocol catalog. The PlotScope OEM7 source
selects a message definition by log name and header CRC, then maps the ASCII
body to channels. No EDIE decoder source is vendored.

`nmea_database.json` is generated by `tools/nmea-metadata.py` from pynmea2:

- Source: https://github.com/Knio/pynmea2
- Copyright (c) pynmea2 contributors
- License: MIT

Only sentence metadata (name/type/unit/label) is exported; pynmea2 runtime code
is not vendored. The generated JSON is committed, so normal builds do not need
Python or pynmea2.

`ubx_database.json` is generated by `tools/ubx-metadata.py` from pyubx2:

- Source: https://github.com/semuconsulting/pyubx2
- Copyright (c) pyubx2 contributors
- License: BSD-3-Clause

Only the UBX payload field dictionaries (`UBX_PAYLOADS_GET` and
`UBX_PAYLOADS_SET`) are exported as a machine-readable schema. pyubx2 runtime
code is not vendored. The generated JSON is committed, so normal builds do not
need Python or pyubx2. The u-blox Interface Description remains the
authoritative source; pyubx2 is used as the machine-readable transcription of
the field tables.
